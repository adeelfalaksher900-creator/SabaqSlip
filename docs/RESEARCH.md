# Research, problem hypothesis and differentiation

Research checked 17 October 2026. Sources inform the design; they do not validate local demand or prove this prototype's effectiveness.

## Specific problem hypothesis

For a small community tutoring group, sharing an activity is only half the task. A tutor also needs to recover individual answers and decide what to explain in the next meeting. Requiring every learner to create an account, stay connected during the activity or join an institutional learning system adds steps. A tiny, bilingual, manually exchanged lesson and return file could reduce that burden.

This is a **design hypothesis requiring local validation**. No local interviews, connectivity incidents, usage counts or learning gains are claimed. Before a final Neighborhood Hacks submission, the creator must describe one real instance personally observed, who was affected and how the workflow addresses it. National statistics cannot substitute for firsthand community relevance.

## Existing tools and originality

| Existing approach | What already exists | SabaqSlip's narrower focus |
|---|---|---|
| [Kolibri](https://learningequality.org/kolibri/) and [facility data management](https://kolibri.readthedocs.io/en/latest/manage/data.html) | Established offline learning, educator tools and progress/data syncing. | One small tutor-created activity and a manual return-to-reteaching loop without facility setup or learner accounts. Kolibri is more capable for institutional use. |
| [Lumi](https://lumi.education/en/) | H5P authoring, HTML export and reporting features. | Four original bilingual starters, bounded return files and explicit teaching actions in a focused workspace. HTML export itself is not new. |
| Paper worksheets or messaging a photograph | Familiar low-infrastructure sharing. | Structured answers and confidence can be grouped into the tutor's next-session plan. Paper remains valuable when devices or HTML exchange are unsuitable. |

No claim is made that this is the first offline education tool, the only bilingual tool, or an exhaustive patent or market novelty search. The contribution is a focused implementation and combination of choices for a specific community workflow.

## Local validation plan

With informed tutor/guardian permission where appropriate, test with one tutor and a small group using learner codes only. First observe the existing sharing and review process. Then compare time to prepare the next session, successful file openings/returns, data transferred and whether the tutor can explain each suggested action. Ask learners to solve a different follow-up question at the next session. Do not infer causal learning gains from an uncontrolled small pilot.
